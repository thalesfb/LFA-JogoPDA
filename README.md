# Operação Cofre LIFO — Trabalho 02 (Autômato de Pilha / PDA)

Jogo web interativo desenvolvido para a disciplina de **Linguagens Formais e Autômatos (IFC)**, modelado a partir de um **Autômato de Pilha (PDA)** com 10 estados (`q0` a `q8` e `qf`) e topologia não linear. `q7` e `q8` são fases do mesmo Portão Blindado, não novas salas; o cofre exige consumir uma credencial `C` e uma `K`, em qualquer ordem.
